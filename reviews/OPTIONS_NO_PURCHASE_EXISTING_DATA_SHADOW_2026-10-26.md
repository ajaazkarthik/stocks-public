1. **Complete local source-first coverage, P0**: `tradingview/options/existing_data_shadow.py` CLI defaults to **read-only `--audit-only`** and counts local historical reference archives using SQLite `mode=ro`: original legacy `options_scan_results`, `options_recommendations`, TQS v2, ZeroDTE and original frozen paper observations. Native full `--scan`/ `--scan-all` calls the SAME original `fetch_full_research_observation` to query **TV scan2, Yahoo exact chain, free Cboe OI, Moomoo OpenD exact options and TV expiry IV smile**, with existing TQS metrics, strict quote evidence gate, no coalescing of vendor clocks/prices. Optional `--tv-lenses` calls original authenticated ZeroDTE TV IV/VOI lens only when an existing authorized cookie is present. Cboe CDN free full bid/ask/IV/Greeks endpoint, old TQS IV datasets, Mo(o)moo subscribed order book, IBKR are documented in the preceding source-audit report; no paid Cboe data required. **Nothing overwrites original production DBs**.

2. **Existing IV changes actually analyzed, P2**: new `tradingview/options/legacy_iv_evidence.py` reads existing legacy option scans **mode=ro**, pairs the *same exact* underlying/type/strike/expiry on **distinct application receipt dates** no more than 7 calendar days apart, using the first recorded quote per exact contract per day. No cross-expiry proxies, no mix of strikes, no leakage after as-of. Date-block train/holdout counts, IV log-change vs underlying log-return relationship and 80% residual coverage compare to unchanged-IV baseline. User's actual Mac archive yielded **1,145 matched exact-contract short-horizon pairs**, **738 training / 407 held-out**, 10 distinct pair-end dates, heldout only 3 distinct dates. Model held-out mean absolute log-IV change error **0.085371 vs 0.084656 unchanged-IV baseline (worse)**, nominal 80% interval covers only **67.322%**. This is a *useful negative diagnostic*, and is deliberately **not promoted** into a false 21-day SPY/QQQ/IWM IV forecast.

3. **Existing-data empirical proxy forecast, P3**: new `existing_data_shadow.py::build_reference_forecast` accepts the actual same-day 5y completed Yahoo historical underlying closes, keeps last completed NY date strictly before decision and observed original signal feature date, trains only on complete past **21-day labeled horizons** and chooses **eight nonoverlapping closest prior 21-day full spot-return paths** using past 5/20-day return and RV features. It simulates future days at actual NYSE calendar market closes and reprices the entire currently observed two-leg option vertical with an explicit **current-option-IV-anchored, clipped ±25% realized-volatility-shift assumption** (same proportional shift on both exact legs, no interpolated missing expiry/strike). **TradingView option IV values are percent (e.g., 20.00) and are converted to fractional Black–Scholes inputs (0.20); synthetic fixture IVs are already fractions.** Returns a complete correctly ordered `REFERENCE_PROXY_UNVERIFIED` versioned forecast artifact, with timestamp after observed option receipt, prior-only training cutoff and SHA256 of source prices, explicit 0 projected rate/dividend/assignment/funding assumptions, and a fixed **$20 per spread *assumption* uncertainty allowance**, NOT a calibrated loss/error interval. The original `edge_engine.validate_forecast` adds this explicit non-promotable status, rejects backdating/lookahead and leaves `notifier_eligible=False`. Do **not** call this a validated future option implied-volatility surface; no full 21-session options IV paths in free source. The previous underlying-return/RV validation was negative and is preserved verbatim, not rebranded as option accuracy.

4. **Existing unchanged frozen baseline vs model-edge research decision, P4**: `safe_comparison` calls the unchanged frozen `choose_candidate` from `edge_engine.compare_frozen_to_edge`, enumerates the same original debit/credit eligible 30–60 DTE vertical candidate universe and unchanged original exits/risk, calculates scenario-modeled expected net and stressed risk, and enforces price-specific max debit/min credit cent grid **only if all price/forecast conditions pass**. Results carry exact candidate legs for subsequent *reference* follow-up, decision time, baseline and challenger statuses, cash abstention, source-by-source evidence and separate model-only price limit. **NO broker orders, NO sendable Telegram alert, NO realtime actionable entry, NO automatically invented fills, NO real P/L.** If no trend/expiry/liquidity/source coverage, it keeps the result as a qualified **NO_TREND / NO_FROZEN_ELIGIBLE_CANDIDATES**, and proceeds to other ETF symbols without treating missing histories as a software blocker. A closed NY market/session is labelled `MARKET_CLOSED_OR_CALENDAR_UNAVAILABLE`, not an invented source price.

5. **Forward research journal + optional reference followup, P4**: new **explicit** `--record` with `--scan` or `--scan-all` only creates an isolated 0600 private `~/.config/stocks-options-edge/shadow-comparisons.sqlite`. Each exact snapshot is idempotently recorded as **REFERENCE_ONLY / NOT_MEASURED**. `tradingview/options/shadow_repricing.py` compares any previously recorded **same exact two-leg contracts** with *later* option references at the same future observation; computes a **hypothetical two-leg bid/ask-cross, friction-and-fees net price difference**, explicitly `HYPOTHETICAL_REFERENCE_QUOTE_CROSS`, `NO_BROKER_FILL_EVIDENCE`, not an account fill or realized P/L. Missing either exact future leg is rejected, the cash control is explicitly $0, and repeated same-timestamp observations are idempotent. This enables forward shadow follow-up as quote availability improves, without pretending the original entry/exit was executed. No production paper ledger writes, even with `--record`.

6. **Existing cross-ETF concentration, P4**: `tradingview/options/shadow_factor_risk.py` aligns completed 5y SPY/QQQ/IWM daily underlying closes and computes correlations and historical hypothetical equal-weight 21-session downside, *not option portfolio risk*. Mac **1,255 paired completed sessions**, average off-diagonal daily return correlation **0.8589**, worst historic 21-session equal-weight underlying log-return **-0.153276**. Flag exposure concentration, do not claim three ETF options as independent trades. Optional `--factor-check` enables this in the audit/scan without extra data purchases.

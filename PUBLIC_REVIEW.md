# Stocks — public source-code review snapshot

This is a **sanitised, one-commit review export** of a separate private trading
application. It intentionally excludes account data, session profiles, broker
statements, credentials, runtime configurations, archives, private reports and
other operational artifacts. It is not intended to run against production
accounts, and is not guaranteed to include all runtime dependencies or datasets.

**Do not put real API keys, credentials, personal trading data or browser
profiles into this public repository.** The source repository remains private.
